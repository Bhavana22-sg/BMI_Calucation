# BMI_Calucation

📌 Project Overview

A simple Python-based BMI Calculator that calculates a person's Body Mass Index (BMI) using their weight and height. The program also displays the corresponding BMI category.

🎯 Objective

To calculate BMI using Python.
To classify the BMI into different categories.
To practice user input, calculations, conditional statements, and error handling.
To handle invalid inputs such as negative values and non-numeric input.

⚙️ How It Works

Enter Weight
     ↓
Enter Height
     ↓
Validate Input
     ↓
Calculate BMI
     ↓
Check BMI Category
     ↓
Display BMI & Category

📊 BMI Categories

BMI Range	Category

Below 18.5	Underweight
18.5 – 24.9	Normal
25 – 29.9	Overweight
30 and above	Obese

🛠️ Technologies Used

🐍 Python
💻 Python IDLE

✨ Features

User-friendly input
Automatic BMI calculation
BMI category classification
Input validation
Error handling
BMI displayed to 2 decimal places

✅ Result

Successfully developed a Python-based BMI Calculator that calculates BMI, identifies the corresponding category, and handles invalid user inputs.
